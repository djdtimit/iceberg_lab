## Deviations

- **Lakekeeper, error_body: unknown_route**: Lakekeeper answers a path it does not have (404) or a method a path does not support (405) with an empty body - no Iceberg error document (Iceberg clients cannot parse the error; same as unitycatalog#1835)
- **Lakekeeper, error_body: unsupported_method**: Lakekeeper answers a path it does not have (404) or a method a path does not support (405) with an empty body - no Iceberg error document (Iceberg clients cannot parse the error; same as unitycatalog#1835)
- **Reference, error_body: unsupported_method**: The Iceberg REST fixture answers an unsupported method (PATCH) with 501 and an empty body instead of an Iceberg error document
- **Lakekeeper, snapshots_value**: Lakekeeper accepts any value of loadTable's 'snapshots' parameter (spec: all|refs; Unity, Polaris and RustFS answer 400)
