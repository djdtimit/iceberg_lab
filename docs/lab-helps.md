# Lab helps: without and with

Generated by `scripts/lab_helps_doc.py`. Some engines cannot connect to a catalog with their stock setup, but a sensible workaround gets them there (list: `iceberg_lab.config.HELPS`). The lab applies it in every run, and a test that works with it counts as working - that is the comparison. The gap itself is shown once per engine by `tests/security/test_stock_connection.py` (area "Connection without help"). The run without help (`LAB_NO_HELP=1`) runs the tests of these engines once more without the workaround; it is shown here and in the dashboard next to the comparison, never counted.

## RustFS

- **pyiceberg, polars, daft**: PyIceberg's SigV4 adapter sends x-amz-content-sha256 only for empty bodies; RustFS rejects every signed POST without it - help: the lab adds the header to every signed request (engines._add_content_sha256).
- **duckdb**: DuckDB derives the SigV4 service from an AWS host name; rustfs:9000 cannot be attached - help: the lab attaches the catalog under an AWS-style alias of RustFS (RUSTFS_AWS_HOST).
